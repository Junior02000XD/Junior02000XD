### 🚀 Proyectos

**[First Class Listening](https://firstclasslistening.com)** — plataforma de acceso a
audios y videos para **First Class Institute** (instituto de inglés). Cada libro físico
incluye un código de canje único: el alumno lo vincula a su cuenta y desbloquea el
contenido de audio/video de ese libro. Producto en producción: API en .NET 10 +
PostgreSQL, frontend en React, entrega de contenido vía Cloudflare R2 con un Worker
que valida tokens JWT antes de servir el stream.
`.NET 10` · `React` · `PostgreSQL` · `Cloudflare R2/Workers`
→ [API](https://github.com/Junior02000XD/first-class-listening-api) · [Web](https://github.com/Junior02000XD/first-class-listening-page) · [Worker](https://github.com/Junior02000XD/first-class-listening-worker)

**[Jalcruz First Class — CRM](https://github.com/Junior02000XD/jalcruz-firstclass-api)** —
sistema a medida con dos módulos sobre la misma base: RRHH para **Jalcruz**, la empresa
familiar (planillas, asistencias), y un CRM de ventas para el equipo comercial de
**First Class** (campañas, prospectos, embudo de conversión, ROI), construido por
iniciativa propia para digitalizar ese proceso. Reescrito de Laravel a .NET 10
manteniendo el mismo contrato JSON para no romper el frontend.
`.NET 10` · `React` · `Tailwind` · `PostgreSQL`

**[Plataforma Integral API](https://github.com/Plataforma-Integral/plataforma-integral-api)** —
proyecto académico final: sistema de gestión educativa (cursos, inscripciones, clases
presenciales/virtuales, pagos, certificados).
`.NET 8` · `SQL Server` · `MinIO`
